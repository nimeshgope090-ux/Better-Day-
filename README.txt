BetterDay PWA - 5 files, keep them together in one folder (no sub-folders):
  index.html  manifest.json  sw.js  icon-192.png  icon-512.png

GitHub Pages: create a public repo, upload all 5 files, Settings > Pages > Deploy from branch > main / (root).
Netlify Drop: drag this folder onto app.netlify.com/drop.
Then open the link in Chrome on your phone > menu > Install app.
